# CV Material

## Project title

**EduAgent — Agentic AI Tutor for Personalized Course Learning**

## Truthful bullets

- Developed a Python and Streamlit educational AI tutor that ingests lecture PDFs, performs course-grounded retrieval with page-aware citations, and supports adaptive explanations and structured quiz generation.
- Implemented a deterministic learner-modeling loop that evaluates quiz answers with structured formative feedback, tracks transparent concept mastery in SQLite, identifies weak concepts, and selects the next teaching action.
- Built a modular OpenAI-compatible provider layer, Chroma vector store, PDF ingestion pipeline, technical retrieval evaluator, deployment configuration, and automated tests for the core deterministic modules.

## Accuracy note

These bullets describe implemented capabilities only. They do not claim student counts, production usage, retrieval accuracy, learning gains, or a completed public deployment.
